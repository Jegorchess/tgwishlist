# Беклог

Статуси: ✅ готово · 🔜 наступне · ⏳ заплановано · 💡 ідея

## Ітерація 0 — фундамент ✅
- Скелет backend (FastAPI, `/health`, `/api/me`, валідація `initData`) і frontend (React + Vite).
- Бот з командою `/start` та кнопкою відкриття Mini App.
- Docker Compose + Caddy, CI, шаблони issues/PR, субагенти.

## Ітерація 1 — мій вішліст 🔜
| ID | Історія | AC (скорочено) |
|---|---|---|
| W-1 | Як користувач, я хочу, щоб мій профіль створювався автоматично при першому вході | Перший запит з валідним `initData` створює `user`; повторний — не дублює |
| W-2 | Як власник, я хочу додати бажання (назва, посилання, ціна, фото, пріоритет, нотатка) | Назва обов'язкова; посилання — валідний URL; ціна ≥ 0 |
| W-3 | Як власник, я хочу бачити свій список бажань | Сортування за пріоритетом, потім за датою; порожній стан з підказкою |
| W-4 | Як власник, я хочу редагувати і видаляти бажання | Лише свої; видалення з підтвердженням |

Технічне: SQLAlchemy 2 (async) + Alembic, таблиці `users`, `wish_items`.

## Ітерація 2 — сім'я ⏳
| ID | Історія | AC (скорочено) |
|---|---|---|
| F-1 | Як організатор, я хочу створити сім'ю | Створювач стає `owner`; генерується `invite_code` |
| F-2 | Як організатор, я хочу поділитися посиланням-запрошенням | Посилання `t.me/<bot>?startapp=join_<code>`; кнопка «Поділитися» |
| F-3 | Як родич, я хочу приєднатися за посиланням | Відкриття Mini App з `start_param` додає в сім'ю; повторно — без дублю |
| F-4 | Як член сім'ї, я хочу бачити список учасників і їхні вішлісти | Лише своя сім'я; чужий список — тільки читання |
| F-5 | Як організатор, я хочу перегенерувати інвайт-код / видалити учасника | Старе посилання перестає працювати |

## Ітерація 3 — продакшн ⏳
- Деплой на VPS: домен, Caddy HTTPS, `docker compose up -d`.
- Бот через webhook замість polling.
- Реєстрація Mini App у @BotFather (`/newapp`, кнопка меню).
- Бекапи PostgreSQL (cron + `pg_dump`).
- Бойове тестування з сім'єю, збір фідбеку.
